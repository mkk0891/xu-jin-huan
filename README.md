# 须尽欢

须尽欢是一个面向隧道转发场景的管理面板，当前版本围绕用户权限、隧道授权、流量计费和节点监控做了深度改造。

## 主要能力

- 用户权限直接承载总流量、转发数量、到期周期和可用隧道。
- 支持按用户隧道单独配置流量、到期时间和计费方式。
- 支持端口转发与隧道转发，覆盖 TCP、UDP 等常见转发场景。
- 支持节点在线监控、系统状态上报和一键复制节点安装命令。
- 支持流量账本与周期结算，并默认保留较短历史，减少数据库空间占用。
- 支持网站名称、后端地址、验证码等基础配置。

## 快速部署

面板默认后端对外端口为 `6666`，前端端口由部署脚本配置。

```bash
curl -L https://flux.mkk01.dpdns.org/panel_install.sh -o panel_install.sh && chmod +x panel_install.sh && ./panel_install.sh
```

节点安装命令建议在后台“节点监控”里复制，系统会自动带上面板地址和节点密钥。
